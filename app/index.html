Honest limits

Detection is capped at 5/10 by the metadata indicators: five incidents leave no trace in registry metadata. The rules-only baseline matches the agent's false-alarm rate; the agent adds cited evidence (11/11 precision vs 11/17 single-shot), explanations, and a path to compiled rules. Some rules were tuned after seeing results on the same cases; the synthetic override layer and the answer key are declared in the README.
